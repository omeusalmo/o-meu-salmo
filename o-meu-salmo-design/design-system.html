6 — Acessibilidade · WCAG 2.1

AA exige 4.5:1 (texto normal) · 3:1 (texto grande ≥18pt ou ≥14pt bold) · AAA exige 7:1. Ícones/grafismos: 3:1 mínimo.

Regras semânticas
Semantics(label, button:true) — todo GestureDetector interativo deve ter label. Botões: Voltar, Compartilhar, Favoritar, Configurações, Ler a reflexão, Ouvir/Pausar áudio.
EyebrowLabel uppercase — TalkBack leria letra-por-letra. Usar Semantics(label: texto, excludeSemantics: true) com o texto em case original.
Movimento reduzido — verificar MediaQuery.disableAnimations antes de iniciar animações não-essenciais; usar ctrl.value = 1.0 em vez de forward().
Opacidade em texto — withAlpha() em texto reduz contraste efetivo. Usar cor plena (night-text ou day-text). Opacidade é permitida apenas em elementos puramente decorativos.
Número de versículo — cobalt-400 a 10px no escuro = ~4.2:1 (abaixo de AA). Funciona como marcador decorativo; conteúdo essencial é o texto do versículo. Documentado como exceção controlada.
nightMuted e dayMuted — valores atualizados para AA: nightMuted #7080C8 5.2:1, dayMuted #4E5899 6.2:1. Aceitos para labels metadata ≥10px, dots e separadores. Nunca para corpo de texto — usar night-text / day-text.
