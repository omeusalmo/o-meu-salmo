O App

Para cada emoção,
o Salmo certo.

O meu Salmo não é mais um app de leitura bíblica. É um devocional diário, uma experiência de conforto. Os 150 Salmos organizados em 8 coleções por emoção. Você escolhe como está se sentindo, o app encontra as palavras. Cada Salmo tem texto completo em português, narração em áudio sem pressa e uma reflexão. Os favoritos ficam salvos no dispositivo, offline, sem internet. Para católicos e evangélicos.
